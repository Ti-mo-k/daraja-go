# daraja-go

A Go client library for integrating with Safaricom's M-Pesa Daraja API.

## Features

- OAuth 2.0 client-credentials authentication
- Access token caching and automatic refresh
- STK Push (Lipa Na M-Pesa Online)
- STK Push callback parsing
- Callback metadata helpers
- Request validation
- Context-aware HTTP requests
- Configurable HTTP client
- Functional client options

## Installation

```bash
go get github.com/Ti-mo-k/daraja-go
